## House rules

- No em dashes or en dashes anywhere: copy, code, comments, commit messages. Use a comma, colon or parentheses.
- One voice only: Kokoro `af_heart` on Together AI, for recorded clips and live lines alike (`src/lib/voice/tts.ts`). Never fall back to the device's speech.
- JYSK's raw listings (`scripts/jysk/facts.json`, `scripts/jysk/cache/`) stay out of git; only the rows built from them in `src/data` ship.
- Every guide is generated by `src/lib/plan` and follows the product's JYSK assembly manual: the same steps in the same order, with the same parts, fittings and counts. Draw and word everything ourselves; JYSK's drawings, photos and text are copyrighted, so never copy them into the app.

## Project Memory (gbrain)

Claude Code auto-memory is off for this repo. Project memory lives in the `gbrain` MCP server (`https://brain.a-z.house`), pages under `jysk/memory/`; `jysk/memory/index` lists every one with a one-line hook. `.mcp.json` connects it with the `mac-jysk` API key from the `GBRAIN_JYSK_TOKEN` env var (kept in the macOS Keychain, exported from `~/.zshrc`; the key file is `/docker/gbrain/tokens/mac-jysk.token` on the brain host).

- Before working in an area, `search` or `recall` the brain for its gotchas, past corrections and conventions. If a search comes back thin, try a second phrasing before concluding nothing is recorded.
- Save a user correction, a confirmed approach or a non-obvious fact with `remember` (`fact`, `provenance` with the date, `entity: "jysk"`). Don't save what the code, this file or git history already records.
- Never write memory files under `~/.claude/projects/`.
- If the `gbrain` tools aren't available (Codex, cloud sessions), say so and carry on without memory.
